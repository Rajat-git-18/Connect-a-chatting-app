# Connect

A full-stack real-time messaging application built with React Native,
TypeScript, Node.js, Express, PostgreSQL and Prisma.

> 🚧 This project is actively under development.

## Current Status

### Completed
- Authentication
- Mobile navigation
- Home feed
- Thread UI
- API foundation

### In Progress
- Thread backend
- Messaging
- Real-time updates
- Production hardening

- Zustand

### Backend
- Node.js
- Express
